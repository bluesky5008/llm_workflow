# 세션 재개 절차

재개 프롬프트("작업 <작업-ID> 재개 — …")나 세션 핸드오프 훅의 재개 안내를 받고 이전 세션의 작업을 이어갈 때 **무엇을, 어떤 순서로, 어디까지 읽는지**를 정한다. 목적은 재개 고정비(읽기 토큰·시간)를 줄이는 것이다 — 인계 한 번의 비용이 크면 컨텍스트 임계 경고에 따른 인계가 토큰·시간 양쪽에서 순손실이 된다([ADR-012](../../../docs/work/20261018-context-signal-v2/ADR-012-컨텍스트-신호-usage-파싱.md) 결과와 감수할 단점). 이 문서를 읽지 않은 재개는 [wf-implement 주의 5항](../SKILL.md#주의--자주-틀리는-것)에 따라 수행하지 않은 것으로 간주한다.

## 1. 읽기 순서 — 최소 집합

아래 순서대로, 각 단계에서 다음 행동을 시작할 수 있으면 멈춘다.

1. **작업 기록의 `## 인계` 절만.** `docs/work/<작업-ID>/work-log.md`를 통째로 읽지 않는다. 절의 위치를 찾아(예: `## 인계` 검색 후 그 행부터) 그 절만 읽는다. 세션 인계의 `다음 행동`은 [wf-doc 인계 블록](../../wf-doc/references/templates.md#인계-블록) 규칙에 따라 대상 TASK·수정 파일·적용 항목 ID를 담고 있어야 한다.
2. **`다음 행동`이 가리키는 TASK의 `plan.md` 항목.** 그 TASK와 `depends:`로 연결된 항목만 읽는다. 작업 목록 전체·계획 트리는 읽지 않는다.
3. **기준선 문서는 항목 단위로.** `req-design.md`·`requirements.md`·`design.md`는 그 TASK가 명시한 FR·DES·AC 항목(앵커)만 읽는다. 전체 읽기는 금지다.
4. **스킬 references는 도달한 단계에서.** 검증 깊이·리뷰 체크리스트 등은 그 단계에 들어갈 때 읽는다.
5. **그 외는 `다음 행동`이 명시적으로 가리킬 때만.** 수행 기록, 검증 결과, 완료 보고, 다른 작업의 기록, `docs/research/`는 재개 시 기본 읽기 대상이 아니다.

## 2. 현재 상태 재확인의 경량 수행

[§3.1 현재 상태 재확인](../SKILL.md#31-현재-상태-재확인)의 항목은 문서를 더 읽는 대신 저장소 명령으로 확인한다.

| 재확인 항목 | 수행 방법 |
|---|---|
| 기준선 이후 저장소 변경 | `git log --oneline -5`, 인계 절의 마지막 갱신일과 대조 |
| 미커밋 변경 | `git status --short`를 인계 절의 "미커밋 변경" 한 줄과 대조. 불일치는 다음 행동 전에 기록 |
| 테스트·빌드 상태 | 대장 `유지` 행은 마지막 성공 SHA가 HEAD와 같고 워킹트리가 clean이면 **인용**한다. 재개 직후 전량 재실행하지 않는다 — 재실행 조건은 [검증 깊이](verification-depth.md)가 정한다 |
| 기준선 적용 가능성 | 1절 3단계에서 읽은 항목 범위에서만 판단한다 |

## 3. 읽기 범위 확장 조건

다음 경우에만 범위를 넓히고, 넓힌 사실과 이유를 수행 기록의 `발견 사항`에 남긴다.

- 인계 절이 자기완결이 아니다(다음 행동에 TASK·파일·항목 ID가 없다) → `plan.md` 작업 목록 → 그래도 부족하면 `req-design.md`의 `## 요약`과 해당 절. 재개 후 첫 갱신에서 인계 절을 자기완결로 보강한다.
- 다음 행동이 가리키는 코드가 인계 절의 서술과 다르다 → 차이가 설계 의미에 닿는지 판단하는 데 필요한 항목만 더 읽고, 닿으면 [wf-design 반환](../SKILL.md#wf-design과의-역할-경계)을 판단한다.
- 컴팩션 직후 재정렬(훅 `post-compact` 안내)이다 → 1절 1단계만 수행하고, 요약과 인계 절이 다르면 인계 절을 따른다. 작업 기록을 다시 전부 읽지 않는다.

## 4. 금지 — 재개 직후 하지 않는 것

- `req-design.md`·`requirements.md`·`design.md` 전체 읽기
- `work-log.md` 전체 읽기, 다른 작업 폴더 탐색
- 대장 `유지` 행 전량 재실행(2절 조건에서 인용)
- 계획 재수립. 기존 계획을 그대로 재개하되, 기준선이 바뀐 경우에만 [design-change §6](../../wf-design/references/design-change.md#6-workflow-2로-반환)에 따라 계획을 갱신한다

## 5. 인계 쪽의 의무

재개 비용은 인계 절의 품질이 결정한다. 세션 인계([wf-implement 세션 인계](../SKILL.md#세션-인계)) 시 `다음 행동`은 재개자가 1절 1~2단계만으로 시작할 수 있게 쓴다 — 형식은 [wf-doc 인계 블록](../../wf-doc/references/templates.md#인계-블록)의 세션 인계 규칙을 따른다.
