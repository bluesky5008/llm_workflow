# 자체 리뷰 체크리스트

[wf-implement §3.5 자체 리뷰](../SKILL.md#35-자체-리뷰)가 소유하는 점검 문항이다. 구현 완료 후 전체 변경 사항을 다시 검토할 때 아래 전 항목을 확인한다. 발견한 문제의 처리(수정과 재검증)와 리뷰의 완료 판단은 본문이 규정한다.

## 요구사항과 설계

- 요구사항과 인수 조건을 모두 충족하는가?
- 승인된 설계와 구현이 일치하는가?
- 설계와 달라진 부분이 기록되었는가?
- 불필요하거나 범위 밖인 변경이 포함되지 않았는가?

## 정확성과 안정성

- 오류 처리와 경계 조건이 충분한가?
- 실패 시 데이터와 상태가 일관되게 유지되는가?
- 재시도, 동시성, 중복 실행 문제가 없는가?
- 변경이 닿은 보호 스코프의 테스트를 Breaking·Stale·Missing으로 분류해 처리했는가?

## 보안과 운영

- 인증, 권한, 입력 검증이 적절한가?
- 비밀 정보나 개인정보가 노출되지 않는가?
- 데이터 손실 또는 하위 호환성 위험이 없는가?
- 로그와 오류 메시지가 운영에 충분하고 안전한가?

## 품질

- [결정 사다리(2.4)](../SKILL.md#24-최소-구현-원칙--ponytail-full-모드)를 통과하지 못하는 불필요한 코드, 추상화, 의존성이 남아 있지 않은가?
- 테스트가 2.4의 작성 기준과 [냄새 체크리스트](verification-depth.md#4-테스트-작성-체크리스트)를 통과하는가?
- 인용한 검증의 SHA가 HEAD와 같고 워킹트리가 clean인가?
- TDD 사이클을 적용하지 못한 변경에 이유가 기록되었는가?
- 코드가 기존 구조와 스타일에 맞는가?
- 문서와 코드가 일치하는가?
- 디버그 코드, 비밀 정보, 임시 파일이 남지 않았는가?
