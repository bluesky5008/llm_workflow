## 기존 기준선과 설계

- [범위 제외](./req-design.md#제외): "시각 디자인 테마·이미지 제작 — 기본 레이아웃의 텍스트 중심 슬라이드로 생성하고, 시각 테마 적용은 PowerPoint에서 사용자가 수행"
- DES-03: 기본 레이아웃(제목/제목+본문)으로 생성, 폰트 지정 수준의 스타일만.

## 제안 설계

### DES-05 (신설): 디자인 시스템

스크립트가 모든 슬라이드에 자동 적용하는 절제된 저채도·고대비 시스템. 색은 5계열로 제한한다.

| 역할 | 값 | 용도 |
|---|---|---|
| 잉크 | `#24304A` (딥 네이비) | 제목·본문 텍스트, 표지 배경 |
| 배경 | `#FAF9F5` (웜 화이트) | 본문 슬라이드 배경 |
| 강조 | `#1B7A6E` (틸) + 연한 채움 `#E3F0ED` | 제목 언더바, 다이어그램 기본, 키워드 강조 |
| 관문 | `#C05B2E` (번트 오렌지) + 연한 채움 `#F7E7DC` | 승인 관문(★)·경고성 강조 |
| 보조 | `#6A7486` (그레이), 패널 `#F0EEE7` | 보조 텍스트, 코드·트리 패널 |

배치: 표지·마무리는 네이비 배경 + 백색 텍스트, 본문은 상단 제목 + 틸 언더바 + 일관 마진(0.6"). 본문 20pt/17pt(중첩), 코드 13pt 유지.

### DES-06 (신설): 인포그래픽 렌더러

md 단일 소스 원칙을 유지하기 위해 코드 펜스에 태그를 도입한다(DES-01 개정 — 내용은 그대로, 렌더 방식만 지정):

- ` ```flow ` — 세로 흐름도: 각 줄이 노드, 화살표 연결, `★` 포함 줄은 관문 색 (해법 개요 ①)
- ` ```rows ` — 가로 단계 행: 각 줄을 `→` 기준으로 분해해 체브런 행으로 (해법 개요 ②의 기능→스킬 매핑, SEMCo-Work 구동 시나리오)
- ` ```ladder ` — 번호 스텝: 결정 사다리 7단을 번호 칩 + 텍스트로 (사다리 펜스는 한 줄=한 단계로 행 구조만 정리, 문구 불변)
- 태그 없음 — 기존대로 고정폭 텍스트를 패널(연회색 배경) 안에 (디렉터리 트리 등)

카드형 배치 2곳(스크립트의 제목→템플릿 매핑, md 내용 불변): "AI 코딩 위임의 실패 모드"(실패 4종을 2×2 카드 + 결론 밴드), "세션 핸드오프 — 개념과 3층 설계"(A/B/C층을 3단 밴드로). 매핑이 실패하면(제목 변경 등) 일반 불릿으로 폴백한다(fail-soft).
