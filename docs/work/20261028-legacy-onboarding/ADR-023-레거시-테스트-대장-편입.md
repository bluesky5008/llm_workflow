## 요약

- 목적: 대장에 없는 기존 테스트를 기능 작업 전에 `유지`로 올리는 경로와 그 표기를 정한다(04 R-13·R-11).
- 현재 결론 또는 상태: 제안 — A(편입 전이 + 기존 문법) 채택안.
- 다음 행동: 요구사항·설계와 함께 승인 관문.

## 배경

`유지` 진입 조건은 "같은 SHA에서 2회 통과(Green 1회 + TASK `completed` 1회)"다. 기존 코드 저장소의 테스트에는 Green이 없어 이 경로로 들어올 수 없고, 대장에 없으면 가드(`wf-test-guard`·`wf-stop-gate`)가 보호하지 않는다 — 워크플로우 적용 후 에이전트가 레거시 테스트를 기록 없이 고칠 수 있다(04 "편입이 정비보다 먼저"). 레거시 테스트에는 이미 실패 중인 것과 인수 조건 연결이 없는 것이 섞여 있고, 보호 스코프를 손으로 채우기 어렵다.

## 영향을 받는 요구사항과 제약

- FR-01~07, NFR-01(본문 순증 0), NFR-02(판독·훅 무변경), NFR-03(도구 중립).
- 판독기 `regression_guard.py`·`wf-common.ps1`은 상태가 `유지`로 시작하는지만 본다.

## 고려한 대안

| 대안 | 내용 | 판단 |
|---|---|---|
| A | 편입 전이(같은 SHA 2회 실행)를 `유지`의 두 번째 진입 경로로 두고, 실패는 `격리(기존 실패, …)`, 스코프는 `미확정` — 새 상태값·열 없음 | 채택 |
| B | 새 상태값 `편입`·`기존 실패` 추가 | 판독 코드·훅·린트·템플릿 변경, 다인 사이클의 레코드 파일화(R-12)와 두 번 바꿀 위험 |
| C | 편입하지 않고 첫 기능 작업의 TDD 경로로만 점진 등록 | 그동안 레거시 테스트가 무보호 — 04의 문제 그대로 |
| D | 1회 실행으로 편입 | 순서 의존·flaky를 편입 시점에 잡지 못함(LLM 작성 테스트 연구에서 flaky의 63%가 비정렬 순서 의존 — 사람 작성 레거시로의 일반화는 유추) |

## 결정

A를 채택한다.

1. **진입.** 편입은 독립 작업(경량 경로 허용)으로 기능 작업 전에 한다. 같은 SHA·clean에서 묶음마다 2회 실행: 둘 다 통과 `유지`, 불일치 `격리(불일치, …)`, 둘 다 실패 `격리(기존 실패, …)` + `마지막 성공` `없음 — 편입 2회 실패`. 테스트는 수정·삭제·skip하지 않는다.
2. **부분 실패.** 일부만 실패하면 그 테스트만 `격리` 행으로 분리하고 나머지는 러너의 명령줄 제외 옵션을 붙여 같은 SHA에서 2회 재실행해 판정한다. 제외는 편입 시점 예외이며 `격리` 행과 1:1이다 — 제외 대상은 `유지`가 아니므로 주의 ④의 금지에 해당하지 않는다. 편입 뒤에는 §2 `격리` 진입 조건일 때만 같은 방식으로 분리하고, 실패 회피 제외는 금지. 해제는 원 행 명령의 2회 통과로 `마지막 성공`을 갱신하고 `격리` 행을 `병합(→원 행)`으로. 대장 모든 셀에 파이프 문자를 쓰지 않는다.
3. **보호 스코프.** 커버리지 도구가 있으면 행별 커버리지로 채우고 없으면 `미확정`. `미확정` 행은 TDD·리뷰의 관련 행이 아니며 `유지` 전량 시점에 돌고, 변경 범위 뮤테이션에서는 포함한다. `격리` 행은 통합에서 실행해 기록만 한다.
4. **R-11.** 통합 재정비 관문에서 도구가 있으면 변경이 닿은 행과 `미확정` 행을 재계산해 차이를 기록하고 승인 후 반영한다.

## 이유

- 판독기가 접두만 보므로 A는 코드·훅을 바꾸지 않고 규칙 문서만으로 성립한다(NFR-02). 대장 열·상태값 5종이 그대로라 R-12 이관 때도 기계적이다.
- 2회 실행은 기존 진입 조건의 "같은 SHA 2회"를 그대로 따르며, 편입은 테스트를 바꾸지 않으므로 Green 대신 두 번째 실행이 같은 역할을 한다.
- 가드 보호는 `테스트 파일` 열 기준이라 `미확정` 스코프여도 편입 즉시 보호된다.

## 결과와 감수할 단점

- 대형 스위트는 2회 실행 비용이 크다(RISK-01).
- `미확정` 행은 회귀 발견이 TASK `completed`까지 늦다(RISK-03).
- `격리` 행의 테스트 파일은 가드 보호 밖이다(기존 판독, RISK-06).
- 경량 경로라 편입에 사용자 승인이 없다 — 제외 옵션 남용은 FR-03 등록 의무와 경량 기록으로만 막는다(RISK-04).

## 후속 작업

- 외부 저장소 첫 편입에서 행 수·격리 비율·실행 시간·`미확정` 비율 기록, 빈틈은 DCR.
- R-14~R-16 규칙은 첫 편입 결과를 본 뒤.
