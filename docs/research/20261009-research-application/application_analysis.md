### 3.1 게이트 원천 — 대장인가 별도 파일인가 (묶음 A)

- 9월안: `docs/quality-gates.md` ```gates 펜스 + work-log 펜스 가산 병합.
- 지금: 대장 `유지` 행 = "이후 모든 작업에서 통과해야 하는 의무". Stop 훅이 이 행을 실행하면 **게이트 목록과 회귀 목록이 하나**가 되고, `격리` 행 제외가 "flaky 금지"를 자동 충족한다.
- 비대장 항목(시크릿 스캔, 링크 검사, 작업 기록 린트)은 "테스트"가 아니다. 선택지: (a) 대장에 `보호 스코프: 저장소 전체` 행으로 등록, (b) 대장은 테스트만, 게이트 파일 별도. (a)는 단일 원천, (b)는 의미 분리.

### 3.3 work-log 구조 고정 (S7·S21)

- 린트 L2가 H2 8개를 고정, L7이 인계 필드를 고정. 새 절·필드는 H3·표·기존 필드 안에서만. 사이클 3이 `### 테스트 대장 변경`을 `## 검증 결과` 아래 H3로 둔 선례를 따른다.
- 시도 등록부는 작업 단위 사건이므로 work-log H3가 자연스럽고, 훅은 열린 work-log를 이미 열거한다(`Get-WfOpenWorkLogs`). 단 측정 스크립트의 VER 행 파서와 충돌하지 않는 표 형식이어야 한다.

### 3.4 검증 깊이 표의 복원 범위 (S3)

- Q-02에서 뺀 이유는 "요구 7·8과 무관 + 어절". 복원하려면 references §1(시점 표)에 **경로 열**을 더하는 형태가 행 상한(100행, 현재 76) 안에서 가능한 유일한 자리.
- 예산 신호 규칙("threshold 수신 후 새 전체 검증 금지")은 훅 메시지(`threshold.md`)에 두면 본문 어절과 무관하다 — S18과 같은 자리.

### 3.5 wf-tree 렌더 스크립트와 현재 §7

- 사이클 1이 §7을 "Markdown 목록 + ASCII, 온디맨드"로 줄였다. `render.py`는 목록 → ASCII 생성뿐이므로 B층 스크립트 관례(ADR-006)대로 `skills/wf-tree/scripts/`에 두고 pytest를 대장에 등록하면 된다. 손 렌더 금지 트리거 문장은 그대로.
